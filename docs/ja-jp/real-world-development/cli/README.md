**[GitHub Copilot CLI][about-copilot-cli]** は、GitHub Copilot をエージェント型コーディングアシスタントとしてターミナルで利用できるようにします。コードベースを探索し、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンドラインから行えるため、グラフィカルエディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys の一連のワークフローに取り組みます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、操作に慣れます。
2. 星評価の小さな変更を行い、ブラウザーで確認して、最初のプルリクエスト (PR) を手動でマージします。
3. 絞り込み issue から始め、Plan モードで方針を定め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、絞り込みの作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズして、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーで絞り込み機能を確認します。
7. 品質保証 (QA) カスタムエージェントを作成して選択し、要件、カバレッジ、検証の証拠を確認します。
8. 絞り込み機能の変更全体をレビューし、機能の PR に Agent Merge を使います。
9. コンテキスト、モデル、共有、任意の cloud agent への委任に使う便利なスラッシュコマンドを確認します。

ワークショップの焦点を絞るため、PR は2つ作成します。1つ目は星評価、2つ目は絞り込み機能と指示・スキル・QA プロファイル・テストの更新です。絞り込みと品質のワークフローは、会話とブランチを共有するため、各ツールを学びながら前の作業を活用できます。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかのプランが設定された GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランを利用していない場合、認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合、管理者が Copilot CLI を有効にしていることを確認してください。
